## FlyWire FAFB v783 data and derivative assets

This repository does not redistribute the raw FlyWire FAFB v783 source-table
download. Users obtain it independently through the
[FlyWire Codex download portal](https://codex.flywire.ai/api/download).

v783 connectivity and metadata so that the static browser laboratory can run.

licensed by this repository's MIT `LICENSE`. They remain subject to the

Anyone redistributing or using those assets must review the current FlyWire

## Model reference

The LIF equations and parameterization implement the published Shiu et al.
whole-brain model. Cite Shiu et al. (2024), *Nature* 634, 210–219,
doi: [10.1038/s41586-024-07763-9](https://doi.org/10.1038/s41586-024-07763-9),
when publishing work that uses the model.
